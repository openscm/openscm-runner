# CMIP pre-industrial branch test data

Inputs for the CMIP pre-industrial branch (concentration-driven) integration tests.

- `cmip6-ssp245.csv`: CMIP6 SSP2-4.5 (history then scenario), 1850-2100,
  in the input's names and units:
  the 43 GHG concentrations, natural (solar and volcanic) forcing
  and aerosol (and aerosol/ozone precursor) emissions.
  The tests use it for the CMIP6 experiments.
- `cmip7-scen7-m.csv`: the same for CMIP7, from the CMIP7 M scenario
  (`scen7-M`, history then scenario), for the CMIP7 experiments.
  RCMIP phase 3 has no emissions for the CMIP7 scenarios (`scen7-*`),
  so the aerosol emissions are the `historical` experiment's (1850-2023),
  held constant at their 2023 values.

In both, the natural forcing is RCMIP phase 3's,
so it isn't zero in 1850 (see decision B19).

They are generated by `generate_data.py`,
within the environment specified by its PEP 723 inline metadata
and lock file (`generate_data.py.lock`).
It downloads the data from the RCMIP phase 3 protocol
(https://gitlab.com/rcmip/rcmip-phase-3, tag v3.0.1, pinned to its commit
and checked against hashes).
To regenerate the data, run (from this directory):

```sh
uv run --locked --script generate_data.py
```
