# AR6 scenario test data

Inputs shared between tests (and the published AR6 outputs to compare with).

- `ar6-aim-cge-2-2-en-npi2020-900f.csv`:
  the infilled emissions AR6 ran the climate models with
  for AIM/CGE 2.2 EN_NPi2020_900f, as AR6 scenario input
  (our names, from 2015, without Halon1202 in line with the definition)
- `ar6-aim-cge-2-2-en-npi2020-900f-ar6-gsat-percentiles.csv`:
  the temperature percentiles AR6 published for the same scenario
  (MAGICCv7.5.3, after AR6's post-processing)

These two are generated by `generate_data.py`,
within the environment specified by its PEP 723 inline metadata
and lock file (`generate_data.py.lock`).
It extracts them from the AR6 database's climate file
(`AR6_Scenarios_Database_World_ALL_CLIMATE_v1.1.csv`, checked against its hash),
following gcages' `tests/regression/ar6/convert_ar6_res_to_checking_csvs.py`.
The file is from the AR6 Scenario Explorer (https://data.ece.iiasa.ac.at/ar6/).
You have to log in to download it, so the script can't download it.
To regenerate the data, run (from this directory):

```sh
uv run --locked --script generate_data.py <path to the climate file>
```
