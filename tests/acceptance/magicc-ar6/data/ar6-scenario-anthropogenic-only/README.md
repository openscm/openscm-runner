# Acceptance data for `MAGICCAR6AdapterAR6ScenarioAnthropogenicOnly`

The data in this directory (`expected-output.csv`) is generated by
[`../ar6-scenario/generate_data.py`](../ar6-scenario/generate_data.py),
along with the data for `MAGICCAR6AdapterAR6Scenario` (and, to come, its other variants).
We generate them all in one script so the data generation can't get out of sync
between the cases and it is obvious what the difference between them is
(see `CASES` in the script),
rather than people having to diff multi-hundred line files.

The input is the same as for `ar6-scenario`
(`tests/test-data/ar6-scenarios/ar6-aim-cge-2-2-en-npi2020-900f.csv`).
The only difference in the run is that only anthropogenic forcing drives the climate
(MAGICC's `RF_TOTAL_RUNMODUS = "ANTHROPOGENIC"`).

In this mode, MAGICC still reports the solar and volcanic forcing
it would have applied (it only changes the total forcing).
They aren't part of the run, so the adapter doesn't offer them
and they aren't in the expected output.

See [`../README.md`](../README.md) for how the data is generated and its format.
