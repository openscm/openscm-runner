# Acceptance data for `MAGICCAR6AdapterAR6ScenarioCO2ForcingOnly`

The data in this directory (`expected-output.csv`) is generated by
[`../ar6-scenario/generate_data.py`](../ar6-scenario/generate_data.py),
along with the data for `MAGICCAR6AdapterAR6Scenario` and its other variants.
We generate them all in one script so the data generation can't get out of sync
between the cases and it is obvious what the difference between them is
(see `CASES` in the script),
rather than people having to diff multi-hundred line files.

**This may still change**: what is meant by CO2-only is still unclear
(e.g. which feedbacks should be included, see roadmap item B16,
and whether the input is fossil CO2 emissions only
or both fossil and biosphere CO2 emissions, see roadmap item B17),
so this case (and the adapter) may still change.

The input is the CO2 emissions from the same scenario as for `ar6-scenario`
(`tests/test-data/ar6-scenarios/ar6-aim-cge-2-2-en-npi2020-900f.csv`).
Only CO2 forcing drives the climate (MAGICC's `RF_TOTAL_RUNMODUS = "CO2"`)
and everything except CO2 is held at pre-industrial (1750) for the whole run:

- every gas except CO2 is concentration-driven, at its 1750 concentrations.
  This matters even though only CO2 forcing drives the climate:
  MAGICC's CO2 forcing depends on the N2O concentration
  (the overlap term in its `OLBL` forcing method)
  and concentrations of other gases would vary with temperature
  (this is part of the feedback question, see roadmap item B16)
- fossil CH4 emissions are zero (history included).
  Otherwise MAGICC adds the CO2 from their oxidation to the fossil CO2 emissions,
  even if CH4 is concentration-driven
  (it splits the CH4 oxidation implied by the concentrations into fossil and biogenic parts)

As for the anthropogenic-only case, MAGICC still reports every forcing
it would have applied, but only CO2 forcing is part of the run,
so the only forcing outputs are the total and CO2 forcing.

See [`../README.md`](../README.md) for how the data is generated and its format.
